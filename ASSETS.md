# ASSETS.md — Используемые ресурсы проекта

## 1. Общие сведения

Проект не использует сторонние графические и аудиоматериалы, за исключением фавиконки приложения, созданной с помощью встроенного ИИ-генератора платформы Lovable.

Все игровые визуальные элементы отрисовываются программно средствами HTML5 Canvas API, а музыка и звуковые эффекты синтезируются в реальном времени с использованием Web Audio API.

Таким образом, игровой контент формируется преимущественно собственными программными средствами проекта, без использования внешних изображений, текстур, спрайтов, аудиозаписей и звуковых сэмплов.

## 2. Шрифты

В проекте используются бесплатные шрифты из каталога Google Fonts. Подключение осуществляется посредством элемента `<link>` в файле `src/routes/__root.tsx`.

| Шрифт | Назначение | Источник |
|---|---|---|
| **Archivo Black** | Заголовки и логотип | [Google Fonts](https://fonts.google.com/specimen/Archivo+Black) |
| **Russo One** | Акцентные надписи и заголовки глав | [Google Fonts](https://fonts.google.com/specimen/Russo+One) |
| **Rubik** | Основной текст пользовательского интерфейса | [Google Fonts](https://fonts.google.com/specimen/Rubik) |

**Лицензирование:** указанные шрифты распространяются по лицензии SIL Open Font License (OFL), допускающей их использование в коммерческих и некоммерческих проектах на условиях соответствующей лицензии.

## 3. Графические ресурсы

### 3.1. Программная отрисовка

Сторонние изображения, текстуры, спрайты и фотоматериалы в игре не используются. Игровая графика формируется программно средствами 2D Canvas API.

К программно отрисовываемым элементам относятся:

- игровое поле боя и окружение;
- монстры и другие игровые существа;
- башни, ворота и элементы игрового снаряжения;
- фоновые изображения и локации;
- интерфейсные элементы и иконки;
- карта кампании и иллюстрации сюжетных сцен;
- визуальные эффекты, градиенты и частицы.

Основные исходные файлы:

- `src/game/render/creatures.ts` — отрисовка игровых существ;
- `src/game/render/battle.ts` — графика и элементы поля боя;
- `src/game/render/gear.ts` — визуализация игрового снаряжения;
- `src/components/ui-kit/StoryArt.tsx` — графические элементы сюжетных сцен.

### 3.2. Фавиконка приложения

**Единственное исключение из принципа программной генерации графики** — фавиконка приложения.

Она создана с помощью встроенного ИИ-генератора изображений платформы Lovable специально для данного проекта. Фавиконка не является заимствованным изображением из стороннего графического ресурса.

## 4. Звуковые ресурсы

### 4.1. Генерация звука

Проект не содержит сторонних аудиофайлов, музыкальных записей или готовых звуковых сэмплов. Все звуки создаются программно в реальном времени с использованием Web Audio API.

Основная реализация находится в файле `src/game/audio.ts`.

Для генерации и обработки звука используются:

- осцилляторы для синтеза тональных сигналов;
- шумовые буферы для создания шумовых эффектов;
- фильтры для формирования тембра;
- сатурация и компрессия для обработки звука;
- программно реализованный реверберационный эффект.

Комбинация перечисленных компонентов формирует характерное мультяшное звуковое оформление игры.

### 4.2. Музыка и персонажи

Музыкальные темы представлены закодированными последовательностями нот, которые воспроизводятся программным планировщиком с опережающим планированием (look-ahead scheduler).

Голоса монстров в сюжетных сценах также синтезируются программно. Для создания характерных звуковых образов персонажей используются отдельно формируемые звуковые последовательности, имитирующие бормотание.

## 5. Сторонние библиотеки и лицензирование

Для графики и звука не используются сторонние библиотеки ресурсов, содержащие готовые изображения, текстуры, музыкальные композиции или звуковые эффекты.

Использование Google Fonts осуществляется в соответствии с лицензиями соответствующих шрифтов. При распространении проекта необходимо соблюдать условия SIL Open Font License и учитывать применимые требования к распространению шрифтов.

Фавиконка создана с помощью встроенного генератора изображений Lovable. Условия использования и распространения данного ресурса определяются применимыми условиями платформы.

## 6. Итоговая декларация

Визуальное и звуковое оформление игры преимущественно реализовано собственными программными средствами проекта.

- **Графика:** процедурная отрисовка средствами HTML5 Canvas API.
- **Звук:** синтез и обработка в реальном времени средствами Web Audio API.
- **Шрифты:** Google Fonts, лицензия SIL Open Font License (OFL).
- **Фавиконка:** изображение, созданное с помощью встроенного ИИ-генератора Lovable.
- **Сторонние графические и аудиоматериалы:** не используются, за исключением указанной фавиконки.

Настоящий документ описывает происхождение основных графических, звуковых и типографических ресурсов проекта.
