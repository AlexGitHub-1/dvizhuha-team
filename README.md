## 📜 О игре

Обычно в Tower Defense ты строишь башни и сдерживаешь волны. Здесь всё наоборот: башни строит умный гарнизон людей, а ты ведёшь Орду монстров по дороге к Воротам Цитадели. Нужно пробить ворота до того, как кончится время.

Кампания — это 6 регионов и 24 уровня на интерактивной карте мира. Сквозь неё идёт детективная история «Кто сжёг Вересковую Лощину?»: улики, подозреваемые, ложные следы и драматичный финал.

## 🎮 Как играть

1. Собери отряд из пяти монстров в **Лагере**.
2. Выбери уровень на карте и заклинание командира.
3. В бою копится **эссенция** — трать её на призыв монстров.
4. Пробей ворота до конца таймера — получишь золото, черепа и до 3 звёзд.
5. Проиграл? Улучши монстров, открой кейсы, изучи таланты и поменяй тактику.

> Уровни специально не проходятся с первого раза: без прокачки и продуманного состава не победить.

### Управление

| Клавиша | Действие |
|---|---|
| `1`–`6` | Призвать монстра из слота (зажать — призывать подряд) |
| `Space` | Заклинание командира |
| `Tab` | Скорость боя ×1 / ×2 |
| `Esc` / `P` | Пауза (или отмена прицела заклинания) |
| `F` | Полный экран |
| Мышь | Клик по полю или башне — цель для прицельного заклинания |

## ⚔️ Механики

### Монстры
16 бойцов пяти редкостей (обычные → мифические). У каждого своя механика:
- **Гоблин-разведчик** — приманка, башни стреляют в него первым;
- **Осадный Тролль** — броня и удар по башням;
- **Гоблин-подрывник** — взрывается у ворот и башен;
- **Тёмный Шаман** — аура лечения и ускорения;
- **Скелет** встаёт после смерти, **Призрак** невидим, **Ледяной Голем** замораживает башни;
- **Гнилой Толстяк** взрывается ядом, **Вампир** пьёт жизнь, **Феникс** перерождается;
- **Некромант** поднимает павших, **Глушитель Рун** отключает магию;
- **Осадный Таран** и **Катапульта** — осадная техника (катапульта расшатывается от каждого выстрела);
- **Костяной Дракон** летит прямо к воротам, **Владыка Бездны** ослепляет всё вокруг.

Монстров можно улучшать до предела их редкости (обычные до 6 уровня, редкие до 8, эпические и выше до 10). С уровнем у них появляется экипировка.

### Башни и их ИИ
Башни людей действуют как единый гарнизон:
- метка наводчика на самого опасного монстра;
- комбо «заморозка + пушка», без лишних выстрелов по добиваемым целям;
- стойки гарнизона: выдержка, паника, последний рубеж;
- суперзаряды, которые можно сорвать осадой или заклинанием;
- адаптация к составу отряда и память о прошлых поражениях;
- баррикады на дороге и руины-укрытия.

В каждом регионе свои уникальные башни (ледяные шпили, курильницы, колокола, огненные алтари, баллисты) и своя «загадка защиты».

### Заклинания командира
Боевой марш, Кровавый дождь, Тьма, Загробный призыв, Кровавый метеорит, Дымовая завеса, Ярость берсерка.

### Прогрессия
- **Кейсы** с редкостями и гарантией эпика — в «Сокровищнице Орды»;
- **Таланты** — 8 ветвей рун за звёзды кампании;
- **Синергии отряда** — бонусы за удачные сочетания монстров;
- **Ежедневные награды и задания**;
- **Поддержка Орды** — помощь после серии поражений на одном уровне;
- **Деяния** — необычные достижения с косметическими наградами (титулы, рамки, тайные главы Летописи).

### Сюжет
Катсцены с портретами и голосами персонажей перед регионами и после боссов. В **Летописи** — доска расследования с уликами и подозреваемыми.

## 🔊 Звук и настройки

Вся музыка и все звуки синтезируются прямо в браузере, без аудиофайлов: у каждого региона своя запоминающаяся мелодия, у каждого монстра свой мультяшный голос, а в главном меню звучит тихая тема.

В **Настройках** можно отрегулировать громкость (общая, музыка, эффекты, голоса, интерфейс), яркость, тряску экрана, частицы, числа урона, метки целей и другие эффекты.

## 🛠️ Технологии

- **React 19** + **TypeScript**
- **TanStack Start / Router**, **Vite**
- **Tailwind CSS v4**
- **HTML5 Canvas** — поле боя и карта мира
- **Web Audio API** — процедурная музыка и звуки
- **localStorage** — сохранение прогресса и настроек
- **Vitest** — автотесты игровых правил

## 🚀 Запуск

```bash
bun install      # установка зависимостей
bun run dev      # локальный запуск
bun run build    # сборка
bunx vitest run  # тесты
```

## 📁 Структура проекта

```text
src/

    data/      — данные: монстры, башни, уровни, регионы, сюжет, достижения

BRANDBOOK.md   — визуальный стиль игры
```

## Публикация на itch.io

Готовая сборка лежит в папке `dist/` (пересобрать: `bun run build:itch`).

1. Заархивируйте **содержимое** папки `dist` в zip (`index.html` должен быть в корне архива).
2. На itch.io: *Create new project* → *Kind of project: HTML* → загрузите zip и отметьте *This file will be played in the browser*.
3. Размер окна: 1280×720 или больше, включите *Fullscreen button*.
